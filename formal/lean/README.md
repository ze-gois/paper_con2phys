# Lean 4 + Mathlib — planned formal verification

Formal code is intentionally **not yet implemented** here. This directory marks the future Lake project for machine-checking selected mathematical statements appearing in `books/formal_foundations`.

When initialized, pin Lean/Mathlib versions, require compilation without `sorry` or extra axioms beyond the accepted mathematical library, and record a stable theorem ID linking each proof to `mathematics/theorems.yml`.

Rocq and Verus are not part of this initial two-book reorganization.
